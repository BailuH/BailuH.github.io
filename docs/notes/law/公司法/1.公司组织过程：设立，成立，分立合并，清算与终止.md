## 🎯 导论：公司生命的生命周期

根据商事外观主义与组织法原理，公司具有类似于自然人的生命周期，从“设立中法人”过渡到“法人营业”，最终因特定事由进入“清算法人”并走向“终止”。
- **设立（1.1）**：发起人开始筹办事务。
- **成立（3.1）**：取得营业执照之日（设立登记）。 
- **注资变更（4.1） / 法代变更（6.1） / 合并（7.1） / 分立（8.1）**：变更登记，产生对抗善意相对人的效力。    
- **解散/破产（9.1）**：公司停止营业，转为清算法人。    
- **终止（12.1）**：完成注销登记，人格消灭。

## 一、 公司设立：设立人、设立协议与设立责任
### （一） 设立人 / 发起人（Promoter）
1. **有限责任公司（第42条）**：由**一个以上五十个以下**股东出资设立。
    - _【对比旧法第24条】_ 旧法表述为“五十个以下”，新法修正为“一个以上五十个以下”，在立法技术上精确排除了“零”的概念。
2. **股份有限公司（第92条）**：应当有**一人以上二百人以下**为发起人，其中应当有**半数以上**的发起人在中国境内有住所。
    - _【法理衔接】_ 新法承认了“一人股份公司”的合法性（对应旧法第78条的“二人以上”）。人数上限之所以定为200人，是为了与《证券法》关于“公开发行有价证券”的门槛相衔接，超过200人即属于公众公司规制范畴。  

![image.png](https://bailu-1382509292.cos.ap-beijing.myqcloud.com/obsidian/20260626151354325.png)

### （二） 设立协议 / 发起人协议
1. **条文分布**：有限公司对应第43条、股份公司对应第93条。

> 有限公司可以选择不要设立协议，股份公司必须要有

2. **法律性质**：发起人之间的合同（共同行为），奠定了设立阶段的==合伙关系==。这也是《新公司法》第50条、第99条规定发起人之间承担连带出资担保义务的法理基础。
3. **效力期限（学理争鸣）**：
    - _观点一_：公司成立时终止，由公司章程替代。 
    - _观点二（老师赞同）_：**效力延续至公司成立后**。理由在于，协议中的部分条款未必被章程吸收，且在认缴制背景下，发起人的诸多出资义务在成立后依然延续。
4. **违约责任**：若发起人违反协议，彼此间产生合同法上的违约责任。《新公司法》在第49条和第107条删除了旧法关于违约责任的赘述，并不意味着取消该责任，而是回归民法典民事责任的一般体系。
5. **章程制订的“一字之差”**：有限公司股东“共同**制定**”章程（第45条），股份公司发起人“共同**制订**”章程（第94条）。
    - 在募集设立股份公司时，发起人先“制订”，再交付创立大会以多数决“通过”；而在发起设立时，仍采一致同意的合意制。新法一概使用“制订”，在募集设立的语境下略显不够精确。

### （三） 设立行为及其责任连带（⭐核心考点）

根据《新公司法》第44条（通过第107条准用于股份公司），发起人对外行为的民事责任遵循以下规则：

| **行为名义**              | **法律后果 / 责任承担**                         | **法理依据**                 |
| --------------------- | --------------------------------------- | ------------------------ |
| **以设立中公司名义（公司成立）**    | 由**成立后的公司**自然承受                         | 设立中公司与成立后公司的人格承继关系       |
| **以设立中公司名义（公司未成立）**   | 由**设立时的股东（二人以上）**承担**连带债务**，享有连带债权      | 设立阶段对外视为合伙关系             |
| **以发起人个人名义（类似于间接代理）** | 第三人享有**选择权**：请求**公司**或**该股东**承担（择一，非连带） | 类推适用《民法典》第926条==间接代理==规则 |
| **履行设立职责造成他人损害（侵权）**  | 公司或无过错股东承担后，可向**有过错的股东追偿**              | 内部过错追责机制                 |

![image.png](https://bailu-1382509292.cos.ap-beijing.myqcloud.com/obsidian/20260626153928450.png)


- _【随堂案例思考】_ 甲乙相约设立证券公司，甲出资10亿现金，乙以土地作价10亿。后设立失败，甲拿回10亿，但发现乙的土地暴增至40亿。甲主张按合伙清算平分增值（各分25亿）是否可行？
    
    - _解析_：“公司未成立，后果由股东承受”所体现的合伙关系**仅对外具有连带性**，对内各发起人并非真正的合伙合同关系，乙的土地所有权并未实质转移为合伙财产，土地增值仍归原所有人乙所有，甲无权分红。
        

### （四） 募集设立股份公司的特殊责任（第105条）

若股份未募足，或股款缴足后30日内未召开成立大会，认股人有权要求发起人**返还股款并加算银行同期存款利息**（发起人承担连带返还责任）。

## 二、 公司成立与商事登记
### （一） 设立原则：准则主义与行政许可主义
- **一般原则（准则主义）**：第29条第1款。凡符合法律规定条件的，登记机关即应予登记。
- **例外情形（行政许可主义）**：第29条第2款。法律、行政法规规定设立公司必须报经批准的（如金融、证券类公司），应在登记前办理批准手续。
- **外国公司分支机构（第244条）**：采严格的行政许可主义，须经中国主管机关审批。

### （二） 放管服改革成果入法
- **第30条（一次性告知义务）**：商事登记机关对材料不全的，应当==一次性告知补正==，突出商事登记的服务功能。
- **第32条（登记事项精简）**：公司登记事项仅包括名称、住所、注册资本、经营范围、法代姓名、有限公司股东/股份公司发起人姓名。**董监高及章程不再作为登记事项，仅需备案。**

## 三、 公司分立、合并与组织变更

### （一） 公司分立（第222、223条）

1. **分类**：新设分立、派生分立
2. **程序**：

| 步骤                  | 具体内容                                                  |
| ------------------- | ----------------------------------------------------- |
| **1. 董事会拟订分立方案**    | 拟订分立方案，特别应妥善处理财产及债务分割问题                               |
| **2. 股东会决议**        | 股东会以特别决议方式决定，须经代表**2/3以上表决权**的股东通过                    |
| **3. 签订分立协议**       | 就资产分割、债权债务分担、股权安排等达成一致协议                              |
| **4. 编制资产负债表和财产清单** | 编制资产负债表及财产清单，进行财产分割                                   |
| **5. 通知和公告债权人**     | 自作出分立决议之日起**10日内**通知债权人，并于**30日内**在报纸上公告              |
| **6. 办理登记**         | 解散分立的，原公司办理注销登记，新设公司办理设立登记；存续分立的，原公司办理变更登记，派生公司办理设立登记 |

1. **后果**：分立前的债务由分立后的公司承担**连带责任**。_【但书例外】_：分立前与债权人就债务清偿达成的书面协议另有约定的除外。

### （二） 公司合并（第218-221条）

1. **分类**：吸收合并（A+B=A，B解散）、新设合并（A+B=C，AB均解散）。
2. **程序（债权人特别保护）**：10日内通知，30日内公告。**债权人自收到通知30日内（未收到自公告45日内），有权要求公司清偿债务或提供相应担保（第220条）。**

| 步骤                  | 具体内容                                                                              |
| ------------------- | --------------------------------------------------------------------------------- |
| **1. 董事会拟订方案**      | 董事会拟订合并方案，内容包括合并原因、目的、合并后各公司的地位、财产及债务处理等                                          |
| **2. 股东会决议**        | 股东会依照章程规定作出决议。合并属于重大事项，必须经代表**2/3以上表决权**的股东通过（有限公司）或出席会议股东所持表决权的**2/3以上**通过（股份公司） |
| **3. 签订合并协议**       | 合并各方签订合并协议，明确资产、债权、债务的处理                                                          |
| **4. 编制资产负债表和财产清单** | 合并各方编制资产负债表及财产清单                                                                  |
| **5. 通知和公告债权人**     | 自作出合并决议之日起**10日内**通知债权人，并于**30日内**在报纸上公告                                          |
| **6. 债权人异议权**       | 债权人自接到通知书之日起**30日内**，未接到通知书的自公告之日起**45日内**，有权要求公司**清偿债务**或**提供相应担保**              |
| **7. 办理审批手续**       | 依法办理有关审批手续（如涉及外商投资、国有资产等需经主管部门批准）                                                 |
| **8. 办理登记**         | 合并后存续的公司办理变更登记，新设的公司办理设立登记，解散的公司办理注销登记                                            |

1. **后果**：合并各方的债权、债务由合并后存续或新设的公司**当然承继**（第221条）。

> 🤔思考：为什么分立与合并债权人保护程序不一致？
> 由于公司合并的时候，可能会引入大量的负债，这对于债权人利益有较大影响，因此债权人==应当不仅享有知情权，更需要同意权/异议权==。
> 相比之下公司分立由于债权人权益的对象没有实质性变化，==仅保护知情权==。

### （三） 新增：简易合并与小额合并（⭐重难点·法定转授权）

依第59条，合并决议本属股东会专属的绝对多数决权力，不可授权董事会。但第219条确立了特例：

```
                      ┌─── 简易合并（第219条第1款）：公司与其持股90%以上的子公司合并。
                      │    （被合并方豁免股东会决议，但须通知少数股东，少数股东享有退股请求权）
股东会决议的法定转授权   ┤
                      │    小额合并（第219条第2款）：合并支付价款不超过本公司净资产10%。
                      └─── （购并方豁免股东会决议，但章程另有规定的除外）
```

- _【法律效果】_ 两种合并可直接由**董事会决议**（须经全体董事三分之二以上通过），董事此时负担更重的信义义务。

#### （二） 司法解散与公司僵局（第231条，司法解释二、五）
1. **公司僵局“三段论”**：公司经营管理发生严重困难 + 继续存续会使股东利益遭受重大损失 + 通过其他途径不能解决。
2. **具体场景（司解二第1条）**：
    - 连续2年以上无法召开股东会；   
    - 股东会表决无法达到法定/章程比例，连续2年无法做出有效决议； 
    - 董事长期冲突且无法通过股东会解决。
    - _【注意】_ 仅以知情权受损、亏损、财产不足、被吊销未清算等提起司法解散的，法院不予受理。
3. **诉讼程序要点**：
    - **原告**：持有公司**10%以上表决权**的股东（新法剔除了“单独或合计持有全部股东表决权”的模糊表述）。
    - **被告**：**公司**。原告若起诉其他股东，应变更为第三人。
    - **司法调解优先**：调解手段包括公司回购、股东受让、他人受让、减资、分立等（司解五第5条）。
    - **判决效力**：对全体股东具有==对世效力==；驳回后原告不得以同一事实和理由再次起诉。

### （三） 清算义务人制度的重大历史变革（⭐⭐极重要）

《新公司法》第232条对旧法第183条、司解二第18条进行了颠覆性修订，彻底纠正了“九民纪要”所关注的“小股东因怠于清算导致巨额背债”的利益失衡问题。

```
旧法/旧司解：有限公司清算义务人为【全体股东】 ──> 导致不参与经营的小股东动辄承担连带清偿责任（极为不公）。
新公司法：明确【董事】为公司清算义务人 ──> 贯彻“平时经营、临了送终”的法理，股东不再直接承担清算义务。
```

1. **职责划分**：
    - **清算义务人（董事）**：负责在解散事由出现15日内**组建清算组**。未及时履行给公司或债权人造成损失的，承担**赔偿责任**（第232条第3款）。
    - **清算人（清算组成员）**：原则上由董事组成（章程或股东会另有选定除外），负责**实施清算事务**。因故意或重大过失给债权人造成损害的，承担**赔偿责任**（第238条第2款）。

### （四） 新增退出机制（市场主体登记管理条例上升为法律）

1. **强制清算（第233条）**：清算义务人逾期不成立清算组或“成立后不清算”的，利害关系人（含少数股东）可申请法院强清。
2. **简易注销（第240条）**：存续期间未产生债务或已清偿全部债务的，经**全体股东承诺**，可通过信息公示（不少于20日）后简易注销。**若承诺不实，股东对注销前债务承担连带责任。**
3. **强制公告注销（第241条）**：被行政解散满3年未申请注销的，登记机关公示60日后无异议可直接注销。但原股东的出资责任及清算义务人责任不受影响。

## 五、 公司组织过程中的三类登记效力

1. **设立登记（第33条）**：**生效要件**。营业执照签发日期为公司成立日期，法人资格自此诞生。电子执照与纸质执照具有同等法律效力。
2. **变更登记（第34条）**：**对抗要件（商事外观主义）**。未经登记或变更登记，**不得对抗善意相对人**（类推《民法典》第64、65条）。例如，法代变更未登记，原法代对外签署的合同可能构成表见代表。
3. **注销登记（第37条）**：**生效要件**。清算结束+注销登记完成 = 公司法人人格彻底消灭。
