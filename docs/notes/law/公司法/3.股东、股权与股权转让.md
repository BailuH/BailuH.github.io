## 二、 有限责任公司的股权转让

### （一） 基于法律行为的股权变动模式（第86、87条）

新公司法厘清了股权转让在合同法与组织法上的交织关系，确立了以下变动法序：

```
签署股转协议 ──> 书面通知公司变更股东名册（第86条） ──> 公司变更股东名册记载（受让人取得股东资格） ──> 办理工商变更登记（产生对外对抗效力，第34条）
```

![image.png](https://bailu-1382509292.cos.ap-beijing.myqcloud.com/obsidian/20260628152316829.png)

- _【组织法效力点】_ **“受让人自记载于股东名册时起可以向公司主张行使股东权利。”** 登记机关的变更登记仅具有对抗善意第三人的效力。

### （二） 股东优先购买权制度的革命性重构（⭐⭐⭐核心大考点）

《新公司法》第84条对旧法第71条进行了重大简化，彻底取消了对外转让股权需“经其他股东过半数同意”的繁琐人头决程序。

| **比较维度**   | **2018年旧公司法第71条**              | **2023年《新公司法》第84条**                 |
| ---------- | ------------------------------ | ----------------------------------- |
| **对外转让条件** | 双重门槛：**过半数同意** + **同等条件优先购买权** | 单一门槛：直接适用**同等条件优先购买权**              |
| **通知义务**   | 仅通知“征求同意”                      | 须将股权的**数量、价格、支付方式和期限**等同等条件书面通知其他股东 |
| **答辩期间**   | 30日内未答复视为同意转让                  | 30日内未答复**视为放弃优先购买权**                |
| **多方主张冲突** | 协商不成按出资比例                      | 协商不成按转让时各自的出资比例                     |
| **章程自治**   | 公司章程另有规定的，从其规定                 | 公司章程对股权转让另有规定的，从其规定                 |

- _【核心学理阐述】_ 优先购买权的本质在于维护有限公司的“==人合性==”**。然而，旧法赋予的“同意权”在实践中极易沦为大股东压制小股东转让自由的工具。新法弱化同意权、强化同等条件竞价机制，表明在价值位阶上，**“转让方的产权变现自由”高于“其他股东盲目维系的人合性”。其他股东若欲维系人合性，必须真金白银支付对价。
- _【权利反悔权】_ 优先购买权属于组织法上的特殊程序性权利，在其他股东主张优先权后，转让方在未签署最终合同前原则上享有“反悔不卖”的权利，故其不属于纯粹的交易法形成权。

### （三） 异议股东评估请求权（强制公司回购，第89条）

1. **有限公司适用情形**：公司连续5年盈利且符合分红条件但不分红；公司合并、分立、转让主要财产；营业期限届满通过决议修改章程使公司存续。
    
2. **新增：控股股东滥用权利之救济（第89条第3款）**：控股股东滥用权利，严重损害公司或其他股东利益的，其他股东有权请求**公司按照合理价格收购其股权**（为打破大股东欺压提供了极为强力的法学武器）。

### （四） 共有股权分割与继承

- **股权继承（第90条）**：自然人股东死亡，合法继承人可当然继承股东资格，**但章程另有规定的除外**。
- **夫妻共有股权分割（司解一第73条）**：涉及离婚分割诉讼时，非股东配偶欲取得股权，须比照对外转让程序：经其他股东过半数同意（新法背景下应类推为不主张优先购买权）。股东不同意且愿意购买的，分割财产；既不同意购买又不主张优先权的，视为同意，非股东配偶可以入股。

## 三、 股份有限公司的股份转让

### （一） 股份转让的基本政策

- **自由转让为原则**：第157条明确股份可自由转让，但同时承认了两面性——**“公司章程对股份转让有限制的，从其规定”**（闭锁性股份公司的兴起，两类公司如同质化）。
- **统一的变动模式（第159条）**：全面取消无记名股票，所有股票转让采取“背书或法律规定的其他方式”进行，并变更股东名册。在股东会召开前20日内、股利分配基准日前5日内，闭籍期内不得变更股东名册。

### （二） 特定群体的限售规定（禁售股，第160条）

1. **公开发行前股份（Pre-IPO股）**：自上市交易之日起**一年内**不得转让。
2. **董监高“限售双重门”**：任职期间每年转让不得超过持股总数的**25%**；上市一年内不得转让；离职后**半年内**不得转让。
3. **新增：限售股设质之效力（第160条第3款）**：股份在限售期内可以出质，但**质权人不得在限制转让期限内行使质权（变现）**。
    - _【效力分析】_ 本款旨在限制权利的变现方式而非剥夺处分权。根据最高院《合同编通则司法解释》第18条，违反该款设立质权的行为**并非无效**，仅产生限售期内无法强执变现的履行障碍。


### （三） 股份公司的股份回购（第162条）

公司原则上不得收购本公司股份，法定的**六大例外情形**包括：
1. 减资（10日内注销）；
2. 与持股本公司股份的其他公司合并（6个月内转让或注销）；
3. 员工持股或股权激励；
4. 异议股东请求回购；
5. 可转债转股；
6. 上市公司为维护公司价值及股东权益所必需。

- _【程序与限额】_ 第（三）、（五）、（六）项情形，可经章程授权由三分之二以上董事出席的董事会决议；公司合计持股不得超过总额的**10%**，并须在**三年内**转让或注销。
- **绝对禁止项**：公司**不得接受本公司的股份作为质权的标的**（防止资本变相抽逃）。

## 四、 上市公司公司治理之特别规制

### （一） 绝对禁止股权代持（第140条）

1. **条文表述**：上市公司必须真实披露股东信息，**“禁止违反法律、行政法规的规定代持上市公司股票”**。
2. **法律效力（⭐重大审判规则）**：不同于普通有限公司代持协议的合法有效性，**上市公司股权代持协议一律无效**。
    - _【法理/案例衔接】_ 援引最高院“天策实业案（2017）”裁判要旨：上市公司的穿透式监管涉及广大不特定投资人的公共利益与金融安全。隐名代持游离于监管之外，会累积金融风险、损害资本市场基本秩序。因此，代持协议因违反《民法典》中的“公序良俗”及证券监管根本利益而归于绝对无效。

### （二） 禁止子公司反向持股（第141条）

1. **双向持股禁止**：**上市公司控股子公司不得取得该上市公司的股份**。
2. **被动持有的修正**：因合并、行使质权等被动持有的，**不得行使对应的表决权**，且应当**及时处分**。该特则彻底杜绝了母子公司利用循环持股虚增资本、操纵表决权的异化现象。
