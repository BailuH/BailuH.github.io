## 第十五章 其他行政行为

### 一、行政确认

> 💡生活中常见的行政确认
> 1. “登记类”的行为（例如婚姻登记、收养登记、不动产登记、**工商登记（登记性质但也包含确认）**）
> 2. 身份与主体资格确认（身份证签发、护照签发、户籍登记、社会组织登记等）
> 3. 公证：如亲属关系公证、学历公证、无犯罪记录公证——公证处作为行政机关（或授权组织）对特定事实的真实性予以确认
> 4. 资格与等级确认（学历学位认证、职业资格认证、残疾登记评定、低保资格认定、烈士评定、伤残等级评定）
> 5. ......

#### （一）概念
行政主体依法对行政相对人相关的**法律事实、法律关系**进行甄别，给予确定、认定、证明并予以宣告的具体行政行为。

#### （二）特征
1. 主体为行政主体；
2. 内容是对法律事实和法律关系的确定；
3. 具有法律效果；
4. **羁束性**行政行为。（行政机关只能严格按照法律规定的条件、程序和结果来执行，==没有自由判断和选择的余地==。*换句话说，只要程序合规就应当进行登记，这和行政裁量不同*）

#### （三）与行政许可的区别
| 比较项 | 行政确认 | 行政许可 |
|---|---|---|
| **行为内容** | 对法律关系与事实的确认 | 赋予权利或解除禁止 |
| **法律效果** | 不赋予新的权利 | 赋予新的权利或资格 |
| **行为方式** | 依申请或依职权 | 依申请 |
| **表现形式** | 确认书、登记证 | 许可证、执照 |

> **实例**：国家工商总局2015年公告明确，商标注册由非行政许可审批调整为具有**行政确认**性质的事项。
> 驰名商标认定本身是是一个**行政确认**，但认定的过程往往又和行政许可密不可分

### 二、行政指导

#### （一）概念
行政主体在履行职责过程中，基于国家法律和政策，在相对人同意或协助下，适时采取**非强制**手段，以有效实现一定行政目的，**不直接产生法律效果**的行为。

#### （二）特征
1. 非权力性，**不具有强制力**；
2. **不直接产生法律效果**；
> 这也是目前==有的时候==我们也不将行政指导算作行政行为的原因。（不过实践中，这种“指导”本身会散发某种法律合规信号）例如，国家行政机关对某些企业进行“**约谈**”（拼多多被罚15亿）

3. 行政机关单方面的意思表示；
4. 适用范围广泛；
5. 形式多样性。

> ❓所有的“指导意见”都是行政指导吗<br>
> [《关于促进全域旅游发展的指导意见》](https://baijiahao.baidu.com/s?id=1595700916192295396&wfr=spider&for=pc)，像这种“指导意见”对象是“对内的”，即上级行政机关对下级机关的工作指导，并不算是行政指导。

#### （三）原则
合法性原则、必要性原则、**自愿性原则**。

#### （四）种类
- 依法律的行政指导 vs 依政策的行政指导；
- 宏观行政指导 vs 个别行政指导；
- 促进性指导 vs 限制性指导。

#### （五）主要方式
说服劝导：如城管劝导地摊商贩等
建议意见
奖励鼓励
协商商谈：如市场监督管理总局（市监局）约谈外卖商家

### 三、行政协议（需要特别关注）

#### （一）概念
行政主体为达到维护与增进公共利益、实现行政管理目标，与公民、法人或其他组织**协商订立**的具有**行政法上权利义务内容**的协议。
> 【**了解就好**】在学术上，行政协议有时候也被称作“行政合同”。
> 要与一般的民事协议（“合同”）区分开，我们要从==行政协议的要素==来判别：
> 1. 主体要素：行政协议的一方是**行政主体**，另一方为**行政相对人**【*需要严格认定该情形*】
> 2. 目的要素：行政协议的目的是维护与增进公共利益、实现行政管理目标
> 3. 内容要素：行政协议具有行政法上的权利义务内容
> 4. 意思要素：行政协议兼具行政性与合意性，是行政主体意思的体现。
   参见：[最高人民法院关于审理行政协议案件若干问题的规定](https://www.court.gov.cn/fabu/xiangqing/207581.html)

#### （二）识别标准（与民事合同区分）

> 💡区分行政协议和民事协议不同是很重要的<br>
> 协议的类型直接决定了当产生纠纷的时候，应当走行政诉讼程序还是民事诉讼程序，前者是行政主体举证，后者是谁主张谁举证。

| 标准       | 内容                                                                              |
| -------- | ------------------------------------------------------------------------------- |
| **形式标准** | 主体一方为行政主体                                                                       |
| **实质标准** | 标的及内容为行政法上的权利义务：（1）是否行使行政职权、履行行政职责；（2）协议或法律是否规定行政机关的**优益权**；（3）是否为实现公共利益或行政管理目标 |
案例：*大英县永佳纸业有限公司诉大英县回马镇人民政府不履行行政协议案*
（2017）最高法行申195号

#### （三）种类
1. 政府特许经营协议；
> 特许经营：
> 烟草（**专卖**）❌  煤炭❌  矿业❌
> 垄断性的公共事业：公共交通✅ 自来水✅
2. 土地、房屋等征收征用补偿协议；
3. 矿业权等国有自然资源使用权出让协议；
4. 政府投资的保障性住房的租赁、买卖等协议；（*保障房、廉租房、经济适用房*，可能不允许）
5. 政府与社会资本合作协议（PPP）；
> 💡PPP在政府环境规制的时候常用

6. 其他行政协议（如息诉罢访协议）。

> **不属于行政协议**：==行政机关之间==因公务协助订立的协议；==行政机关与其工作人员==的劳动人事协议。

#### （四）订立原则
公开公正原则、公共利益原则、严格依法原则。


### 四、行政裁决

#### （一）概念
行政机关依照法律授权，对当事人之间发生的、与**行政管理活动密切相关的民事纠纷**进行审查，并作出判定的行政行为。
改革开放以来，==行政裁决的范围也是越来越狭窄了==（司法备案制度的大力推行）

#### （二）特征
1. 对象为与行政管理密切相关的**民事纠纷**；
2. 主体为**法律授权**的行政机关；
3. 依当事人**申请**启动（意味着行政裁决是一个被动启动的裁决）
4. 具有法律效力。（*意味着也可以不服再上诉*）

#### （三）主要种类
1. **权属纠纷**裁决（如土地所有权与使用权争议）；
2. **侵权纠纷**裁决（如商标、专利侵权纠纷）。

#### （四）原则
裁决法定原则、公平公正原则、简便迅捷原则。

### 五、行政奖励

#### （一）概念
行政主体为表彰先进、激励后进，依照法定条件和程序，对为国家和社会做出突出贡献或模范遵纪守法的相对人，给予**物质或精神奖励**的具体行政行为。

#### （二）特征
1. 主体为国家行政机关或授权组织；
2. 目的在于表彰激励；
3. 对象为突出贡献或模范守法的集体或个人；
4. 内容包括物质与精神奖励；
5. 须符合法定条件、标准、形式、权限和程序。

#### （三）种类与原则
- **种类**：赋予精神权益、赋予物质权益【例如：*张晋藩“人民教育家+500万”*】
- **原则**：依法奖励（如《*国家科学技术奖励条例*》）、奖励与受奖行为相当、精神奖励与物质奖励相结合、公正合理平等、时效性。

### 六、行政给付

#### （一）概念
行政主体在公民失业、年老、疾病或丧失劳动能力等情况或其他特殊情况下，依照有关法律或政策规定，赋予其一定的**物质权益或与物质有关的权益**的行政行为。

#### （二）特征
1. 由特定行政主体作出；
2. 内容为金钱或实物给付；
3. 对象为符合条件的特定相对人；
4. 须严格依法实施。

#### （三）主要种类
抚恤金、特定人员优待金、**最低生活保障金**、自然灾害救济金及救济物资。
> 💡关于低保（最低生活保障金）
> 提出背景：1997年国企市场化改革，减员增效
> 目前已经由城市向乡村拓展
> *低保如何避免“养懒人”？如何公平地发放低保金？*

#### （四）原则
依法给付原则、公平公正平等原则、规范透明原则。

### 七、行政命令

#### （一）概念
行政主体依法要求行政相对人**作出或不作出一定行为**的单方意思表示。

#### （二）特征
1. 由有权发布命令的行政主体作出；
2. 内容要求相对人作出一定行为或保持一定状态；
3. **负担性**行政行为；
4. 依职权单方作出，无需相对人同意；
5. 以行政处罚、行政强制为保障。

#### （三）分类
| 分类标准     | 类型     | 示例                   |
| -------- | ------ | -------------------- |
| **内容性质** | 命令（指令） | 责令拆除                 |
|          | 禁令     | 禁止通行                 |
| **适用对象** | 抽象行政命令 | 交通限行令（针对不特定多数人，反复适用） |
|          | 具体行政命令 | 责令限期改正（针对特定对象，一次性适用） |
