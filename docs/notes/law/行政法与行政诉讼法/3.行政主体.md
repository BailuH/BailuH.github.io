本章的核心在于解决现代行政法中“==谁在代表国家管理公共事务==”以及“==谁来独立对外承担法律责任==”的根本问题。通过本章的学习，应准确掌握*行政主体、行政机关、被授权组织与受委托主体的组织构造与法律法律地位*。

## 一、 行政组织法概述

### （一） 行政组织的内涵

- **定义**：行政组织是指担当行政事务、享有行政权的组织。
- **存在形式**：既可以指某一个特定的行政机构（如国家卫生健康委员会），也可以指由这些特定机构共同组成的有机整体（如整个国务院系统）。
### （二） 行政组织法的概念

行政组织法是**规范和控制行政组织之组成及其相互关系的法律规范的总称**。其核心内涵包含三个维度：
1. **规范设立**：它是规范行政组织设立、变更与撤销的法；   
2. **控制组织**：它是严格控制行政组织规模、编制和内部层级的法；    
3. **划分权责**：它是规定特定行政组织具体职权、职责和管辖范围的法。
### （三） 行政组织法的主要内容

1. **行政机关组织法**：主要包括行政机关的设置、任务、地位、组成、职权、职责、程序、编制等静态与动态的内容（如《国务院组织法》、《地方各级人民代表大会和地方各级人民政府组织法》）。
2. **公务员法**：主要包括行政机关公务员的录用、培训、考核、奖励、惩罚、晋升、调动、退休，以及公务员职务上的权利与义务等内容（如《中华人民共和国公务员法》）。
### （四） 行政组织法的核心功能

- **法律支撑功能**：为行政组织的存在和变革提供合法性依据与制度保障。 
- **权力配置功能**：依法设定权力、分配权力以及动态调整各部门间的权力。  
- **规范和控制功能**：  
    - 明确行政机关的设置标准；    
    - 确定行政组织的内部结构与相互关系；    
    - 严控行政组织的规模与人员编制； 
    - 限制行政权力的外延与边际，防止公权力无限膨胀。  
- **保障功能**：从根本上保障公民相关权利的实现，并保障行政组织本身的变革能够符合公共管理的客观规律。
## 二、 行政主体（Administrative Subject）概念与种类

### （一） 行政主体的概念与四个核心要素

> **行政主体**是指承担行政职责、拥有行政职权，能以自己的名义行使行政权力，并能独立承担因此而产生的法律后果的组织。

要想在法律上成立一个“行政主体”，必须同时满足以下四个核心要素：
1. **权责要素**：必须承担特定的行政职责，并拥有相应的行政职权；
2. **名义要素**：必须能够**以自己的名义**独立对外行使行政权力、发布行政决定；
3. **后果要素**：必须能够独立承担因行使行政权力而产生的法律后果（如作为行政诉讼的被告、承担行政赔偿责任）；
4. **属性要素**：行政主体必须是**组织**，而绝非公务员个人。
### （二） 行政主体的两大基本种类

在我国现行行政法制中，行政主体仅包括以下两类组织：

1. **行政机关**（最主要的行政主体）；
2. **法律、法规或规章授权的组织**。
### （三） 【概念辨析】行政主体 vs 行政法律关系主体

- **行政主体**：特指享有国家行政权、能独立对外承担责任的**组织**。【==本质上是一个诉讼概念==】
- **行政法律关系主体**：是一个宏观概念，包括==行政主体、行政相对人以及行政监督主体==。
- **二者关系**：行政主体是行政法律关系主体的一种，也是其中最核心、最重要的主体。**任何行政法律关系都离不开行政主体**，否则行政法律关系无从成立。

## 三、 行政机关（Administrative Organs）

### （一） 概念及核心内涵
行政机关是依据宪法和组织法成立的、承担国家行政职责、行使国家行政职权的组织。
- **国家代表性**：它是国家设立的、代表国家行使特定职能的组织。
- **职能特定性**：它行使的是国家行政职能，从根本上区别于立法机关（人大）和司法机关（法院、检察院）。
- **设立法定性**：它是依据宪法和专门组织法设立的常设机构，在实践中**具有独立的行政编制**，这使其区别于临时的或受授权的普通组织。
### （二） 行政机关的五大特征

1. **权力的行使性**：承担行政职能，并具体行使国家行政权力。
2. **构造的科层制**：在组织体系上呈现严密的**科层制**（Bureaucracy），讲求上下级的指挥与服从。
3. **决策的首长负责制**：在决策体制上实行首长负责制，区别于权力机关的集体票决制。
4. **运行的常态性与主动性**：依职权主动管理社会事务，且保持常态化连续运转。
5. **主体代表性**：它是最核心的行政主体，在日常话语体系中经常被用来直接指代行政主体。

### （三） 行政机关的成立条件

一个行政机关宣告正式成立并投入运行，通常需具备以下六个硬性条件：

1. 有法定的依据并经法定机关批准；
2. 被赋予法定的职责权限；  
3. **有法定行政编制**并按编制配备人员；  
4. 有独立的行政经费预算； 
5. 有固定的办公地点和必要的办公条件；
6. 经公开宣告正式成立（如：“国家金融监督管理总局正式==挂牌==”案例）。
### （四） 行政机关的职责（义务）与职权（权力）

| **行政职责（行政机关承担的义务）**                                                                                 | **行政职权（履行职责所拥有的手段） **                                                                         |
| --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 1. 维护国家安全<br>2. 维护公共安全与社会秩序<br>3. 维护市场秩序与促进经济发展<br>4. 促进教育科学文化发展<br>5. 提供社会保障与社会福利<br>6. 保护生活与生态环境等 | 1. 行政立法权 <br>2. 规范性文件制定权<br>3. 行政决策权<br>4. 行政命令权<br>5. 行政处理权（如许可、处罚）<br>6. 行政监督权<br>7. 行政裁决权等 |

- 对内机关 与 对外机关。
- **派出机关**（如行署、区公所、街道办） 与 **派出机构**（如公安派出所、工商所）。

#### 2. 【实务微观辨析】直属机构 vs 办事机构

虽然近年来实践中有些机构（如网信办）的角色有所重叠和整合，但传统法理上二者有严格区别：
- **业务性质**：办事机构主要协助政府办理专门事项；直属机构则是主管某项专门行政业务的部门。
- **职能独立性**：直属机构具有独立的行政管理职能，而办事机构原则上不具备。
- **对外执法权**：**直属机构可以独立对外行使职权、作出行政行为**；而办事机构不具有独立对外行使职权的权力。
#### 3. 中国现行行政机关整体架构体系

我国行政机关体系主要由**中央行政机关体系**、**一般地方政府体系**和**特别行政区政府体系**三部分组成。
- **中央行政机关（国务院系统）构成**（依据《国务院组织法》等）：
    1. 国务院组成部门（26个）    
    2. 国务院直属机构（14个）    
    3. 国务院特设直属机构（1个）    
    4. 国务院办事机构（1个）
    5. 部委管理的局（17个）
    6. 在党的中央机关挂牌的机关

- **地方行政机关构成**（依据《地方各级人大和地方各级政府组织法》等）：各级政府、政府组成部门、直属机构、办事机构及议事协调机构。
- **内部组织与“三定”规定**：行政机关的内部组织结构、岗位权责通常由中央或地方组织编制管理部门审核通过的==“三定”规定（职能配置、内设机构和人员编制规定）==进行规范。

## 四、 法律、法规或规章授权的组织（Authorized Organizations）
### （一） 概念与法律属性
指**依具体法律、法规或规章的直接授予**而行使特定行政职能的、**国家行政机关之外的社会组织**。
### （二） 核心特征
1. 它的组织身份**不是国家行政机关**；
2. 它的权力来源必须是**法律、法规或规章的明确授权**（法条直接规定）；
3. 它仅在授权范围内具有特定行政职能；
4. 它在执行授权事务时，**以自己的名义**作出行政行为；
5. 它必须能独立承担因该行为引发的相应法律后果（如做被告）。
### （三） 我国被授权组织的法定范围
实践中，常见的被授权组织主要包括以下六大类：
1. **基层群众自治组织**：如居民委员会、村民委员会（依法管理基层公共事务）；
2. **社会团体**：如工会、共青团、妇联等组织；
3. **行业组织**：如律师协会、注册会计师协会（依法对行业成员实施惩戒或管理）；
4. **事业单位**：如公立学校、高等院校（依法颁发学位证、对学生进行处分）；
5. **企业组织**：如铁路运输企业。
    - _典型法条依据_：《铁路法》第3条第2款规定：“国家铁路运输企业行使法律、行政法规授予的行政管理职能”；
6. **其他组织**。
### （四） 被授权组织的法律地位
- **双重身份性**：被授权组织在行使法律、法规或规章所授行政职能时，**它是行政主体**，具有与行政机关相同的法律地位。
- **责任自担性**：必须以自己的名义行使职权，并由其本身就行使所授职能的行为对外承担民事及行政法律责任。
- **领域有限性**：在其**非行使行政职能的场合**（如学校购买办公用品、招聘教师等民事活动），它不享有行政权，**不具有行政主体地位**。

## 五、 受委托执行行政事务的组织（Entrusted Organizations）
### （一） 行政委托的概念
行政委托是行政主体在其职权职责范围内，**依法**将其职权职责委托给其他组织或个人，受委托者**以委托者的名义**实施相应行为，并**由委托者承担法律责任**的制度。
### （二） 受委托主体的五大特征
1. 就受委托的事务而言，受委托主体**本身不属于合法的行政主体**；
2. 必须接受特定行政主体的书面委托；
3. 实施行政行为时，必须**以委托机关的名义**对外开展，不得用自己的名义；
4. **不承担相应的法律后果**，该行为的法律责任由委托的行政主体全权承担；
5. 行政委托必须具有相关的法律、法规或规章依据，不得任意委托。
### （三） 行政委托的现实动因与依据
1. **解决专业性、技术性事务**：如特种设备安全执法的专业技术委托。
2. **节约行政成本，提高便民效率**。
    - _典型法条依据_：《税收征收管理法实施细则》第44条：“税务机关根据有利于税收控管和方便纳税的原则，可以按照国家有关规定委托有关单位和人员代征零星分散和异地缴纳的税收，并发给委托代征证书”。
3. **解决行政编制不足的问题**：如行政机关设立事业编制的专门执法队，再通过書面委托方式授予其具体的执法权。
### （四） 受委托主体的四大法定类型
1. **其他行政机关**：如《行政许可法》第24条规定，行政机关在其法定职权范围内，可以依法委托其他行政机关实施行政许可。
2. **事业单位**：如《行政处罚法》第20条规定，行政机关可以依法在其法定权限内书面委托符合法定条件的组织实施行政处罚（个人和其他组织除外）。
3. **企业**：如公安部推行的车辆登记销售企业快捷代办服务，委托汽车销售企业一站式代办车牌登记。
4. **个人**：如前述《税收征收管理法实施细则》中依法委托代征税款的特定合规个人。
### （五） 受委托组织的法定限制条件（以行政处罚委托为例）
根据《行政处罚法》的严格规定，受委托组织必须具备以下条件方能接受委托：
1. 依法成立并具有管理公共事务的职能；
2. 有熟悉有关法律、法规、规章和业务，并**取得行政执法资格**的工作人员；
3. 需要进行技术检查或者技术鉴定的，应当有条件组织进行相应的技术检查或者技术鉴定。
### （六） 受委托主体的权利与义务
- **职责与义务**：必须在委托范围内行使职权，不得超越权限再委托；依法规范办理相关事务；接受委托机关的日常监督与业务指导；勤勉尽责。
- **职权与权利**：有权获得委托机关提供的必要执法手段与条件；取得委托合同约定的必要经费或劳务报酬；请求委托机关协助排除执法障碍；向委托主体提出管理方面的合理化建议。
## 六、 【核心考点总结】行政授权 与 行政委托 的区别

在行政法实务中，辨别某一组织究竟是属于“行政授权”还是“行政委托”至关重要，这直接决定了行政诉讼中**被告的认定**。

> **核心鉴别标准**：形式上怎么写不重要（比如很多政府公文里经常混用“授权”或“委托”一词），**本质上必须看有没有明确的法律、法规或规章作为权力的直接对口依据**。有法条直接把权力赋予该非机关组织的，才是真正的“授权”；否则，哪怕文件里写着“授权”，在法律性质上也只能归为“委托”。

|**1. 作用对象不同**|主要面向行政机构和各种特定的社会组织。|范围更为广泛，包括行政机构、其他各类组织以及特定个人。|
|**2. 设定方式不同**|必须由**法律、法规、规章直接规定**，或者由行政主体依据法条规定予以单方授权。|由委托的主体单方签署书面委托书（如《行政执法委托书》），方式更为灵活便利。|
|**3. 法律后果不同**|**职权和职责发生转移**。被授权组织获得**行政主体资格**，能够**以自己的名义**行使职权，并**自己承担**法律责任（行政诉讼中做被告）。|**职权不发生转移**。受委托主体不具有行政主体资格，必须**以委托机关的名义**行使权力，其法律责任由**委托的主体承担**（行政诉讼中仍以委托机关为被告）。|

### 经典实务综合大例：国发〔2020〕4号《国务院关于授权和委托用地审批权的决定》
在这个国务院发布的重磅文件中，完美地展示了“授权”与“委托”在国家级立法实务中的精妙并用：
1. **关于“授权”的规定**：将永久基本农田以外的农用地转为建设用地的审批事项，**授权**各省、自治区、直辖市人民政府批准。各省政府此时是以自己的名义独立行使这项新获得的中央级权力。
2. **关于“委托”的规定**：试点将永久基本农田转为建设用地和国务院批准土地征收的审批事项，**委托**部分试点省、自治区、直辖市人民政府批准。此时试点省政府是在国务院委托的范围内、以国务院的名义代行审批，其最终法律后果和责任仍归属于国务院。
