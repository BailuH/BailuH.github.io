## 第十八章 行政诉讼受案范围

### 一、行政诉讼受案范围概述

#### （一）概念
行政诉讼受案范围指**人民法院受理行政诉讼案件的范围**，也是行政相对人或其他利害关系人对行政行为不服的时候，可以起诉到人民法院的行政行为的范围。

#### （二）行政诉讼受案范围的意义
1. 行政诉讼受案范围标志着**法院可审查行政行为的范围**；
2. 行政诉讼受案范围意味着**利害关系人诉诸法院的范围**；
3. 行政诉讼受案范围影响着**当事人资格的确定**。

#### （三）制约行政诉讼受案范围的因素
1. 公民权利与法治意识发展的程度；
2. 司法机关解决行政争议的能力；
3. 行政机关依法行使职权的状况；
4. 国家民主政治发展情况。

#### （四）行政诉讼受案范围的表述方式
1. **列举式**；
2. **概括式**；
3. **综合式**。

#### （五）我国有关行政诉讼受案范围的规定
1. **对受案范围的总体划定**（《行政诉讼法》第2条）；
2. **对受案范围的正面列举**（《行政诉讼法》第12条）：
   - A. 具体列举；
   - B. 其他涉及人身权、财产权等合法权益的案件；
   - C. 法律、法规规定可以起诉的其他行政案件；
3. **对不可诉行为的排除**（《行政诉讼法》第13条）。

---

### 二、可诉的行政行为及其特征

#### （一）可诉行政行为种类（《行政诉讼法》第12条具体列举）

| 序号 | 可诉行政行为类型 | 核心内容/示例 |
| :--- | :--- | :--- |
| 1 | **行政处罚** | 行政拘留、暂扣或吊销许可证和执照、责令停产停业、没收违法所得、没收非法财物、罚款、警告等 |
| 2 | **行政强制措施和行政强制执行** | 限制人身自由、查封、扣押、冻结等 |
| 3 | **行政许可** | 申请行政许可被拒绝、法定期限内不予答复，或对有关行政许可的其他决定不服 |
| 4 | **自然资源确权决定** | 确认土地、矿藏、水流、森林、山岭、草原、荒地、滩涂、海域等自然资源的所有权或使用权 |
| 5 | **征收、征用及补偿决定** | 对征收、征用决定及其补偿决定不服 |
| 6 | **不履行法定职责** | 申请行政机关履行保护人身权、财产权等合法权益的法定职责，行政机关拒绝履行或不予答复 |
| 7 | **侵犯经营自主权** | 认为行政机关侵犯经营自主权、农村土地承包经营权、农村土地经营权 |
| 8 | **滥用行政权力排除或限制竞争** | 认为行政机关滥用行政权力排除或限制竞争（**案例**：斯维尔公司诉广东省教育厅案——我国首例诉行政垄断司法判决） |
| 9 | **违法集资、摊派费用** | 认为行政机关违法集资、摊派费用或违法要求履行其他义务 |
| 10 | **未依法支付待遇** | 认为行政机关没有依法支付抚恤金、最低生活保障待遇或社会保险待遇 |
| 11 | **行政协议** | 认为行政机关不依法履行、未按约定履行或违法变更、解除政府特许经营协议、土地房屋征收补偿协议等行政协议 |
| 12 | **其他人身权、财产权等合法权益** | 如外部化的内部行政行为（行政批复、会议纪要等） |
| 13 | **其他法律法规规定** | 其他法律法规规定可提起行政诉讼的行为 |

**补充规定与案例**：
- **行政协议**：《最高人民法院关于审理行政协议案件若干问题的规定》（2019年11月12日通过，自2020年1月1日起施行）。
  - **定义**：行政机关为了实现行政管理或者公共服务目标，与公民、法人或者其他组织协商订立的具有行政法上权利义务内容的协议。
  - **案例**：李某某诉淮南市城建委不履行征收补偿协议案。
- **外部化的内部行政行为**：
  - **案例1（政府批复）**：魏永高、陈守志诉来安县人民政府收回土地使用权批复案（最高人民法院指导案例22号）；
  - **案例2（会议纪要）**：吉德仁等诉盐城市政府会议纪要案（2003）苏行终字第025号。
- **政府信息公开案件**：《政府信息公开条例》第五十一条规定，公民、法人或者其他组织认为行政机关在政府信息公开工作中侵犯其合法权益的，可以依法申请行政复议或者提起行政诉讼。

#### （二）可诉作为的特征
1. 是针对特定对象与事项的**具体行政行为**；
2. 是针对公民、法人和其他组织的**外部行政行为**；
3. 有司法审查的必要性（例如：为追求更重的行政处罚）；
4. 在现实情况下有司法审查的可能性。

#### （三）可诉不作为的特征
1. **违反作为义务**（行政主体有相应的职责）；
2. 相对应的作为须具有可诉性；
3. 超过法定期间或合理期间而不作为。

### 三、“一并审查”的范围

#### （一）一并审查的概念
一并审查指公民、法人或者其他组织认为行政行为所依据的**国务院部门和地方人民政府及其部门制定的规范性文件**不合法，**在对行政行为提起诉讼时，可以一并请求对该规范性文件进行审查**。

**核心要点**：
1. 可以有条件地请求法院对规范性文件进行审查；
2. **不能单独**就规范性文件提出审查请求；
3. 被请求一并审查的规范性文件应该是被提起行政诉讼的行政行为的依据。

#### （二）一并审查的规范性文件的范围
1. 国务院部门的规范性文件；
2. 地方人民政府的规范性文件；
3. 地方人民政府部门的规范性文件；
4. **排除范围**：上述规范性文件**不含行政法规和行政规章**，也**不包括国务院的规范性文件**。

### 四、几类不可诉行政行为的界定

| 序号 | 不可诉行为类型 | 界定与说明 | 示例/案例 |
| :--- | :--- | :--- | :--- |
| （一） | **国防、外交等国家行为** | 指国务院、中央军事委员会、国防部、外交部等根据宪法和法律的授权，以国家名义实施的有关国防和外交事务的行为，以及经宪法和法律授权的国家机关宣布紧急状态等行为 | 与特定国家建交或断交的行为 |
| （二） | **具有普遍约束力的决定、命令** | 行政法规、规章或行政机关制定、发布的具有普遍约束力的决定、命令（针对不特定对象、反复适用） | **案例**：设置交通信号灯的行为可诉吗？——徐某等人诉南通市通州区交通运输局案（2020）苏06行终139号 |
| （三） | **对行政机关工作人员的奖惩、任免等决定** | 指行政机关作出的涉及行政机关工作人员公务员权利义务的决定 | 职务任免行为 |
| （四） | **法律规定由行政机关最终裁决的行政行为** | 此处“法律”指全国人大及其常委会制定、通过的规范性文件 | 《出境入境管理法》第81条第2款：外国人违反本法规定，情节严重，尚不构成犯罪的，公安部可以处驱逐出境。公安部的处罚决定为最终决定 |
| （五） | **公安、国家安全等机关的刑事侦查行为** | 依照刑事诉讼法的明确授权实施的行为 | 对聚众斗殴行为的刑事侦查 |
| （六） | **调解行为及法律规定的仲裁行为** | 行政主体居中对民事纠纷进行调解，或依法律规定实施仲裁 | 公安机关对斗殴双方的民事调解 |
| （七） | **行政指导行为** | 行政相对人可自由决定是否按行政主体意志作出相关决定的指导性、建议性行为 | —— |
| （八） | **驳回申诉的重复处理行为** | 行政主体已作出一定行为，当事人依法寻求或放弃救济后，行政主体进行复查并作出相应表述 | 对历史问题的复查 |
| （九） | **不产生外部法律效力的行为** | 行政机关针对内部事宜作出的行政行为，或不对外发生法律效力 | 一般的会议纪要与内部批复 |
| （十） | **过程性行为** | 行政机关为作出行政行为而实施的准备、论证、研究、层报、咨询等 | **案例**：颍上县恒运矸石厂诉颍上县人民政府行政决定与行政强制案（2017）最高法行申295号 |

**最高法裁判要旨（过程性行为）**：
> “在存在复数行政行为的情况下，只有直接对外发生法律效果的那个行为才是可诉的行政行为，其他阶段的行政行为只是行政机关的内部程序。”
> ——颍上县恒运矸石厂诉颍上县人民政府行政决定与行政强制案（2017）最高法行申295号
