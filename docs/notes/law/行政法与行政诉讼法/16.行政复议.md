## 第十六章 行政复议

### 一、行政复议概论

#### （一）概念
行政复议是指公民、法人或其他组织认为行政主体的行政行为侵犯其合法权益，依法向**行政复议机关**提出申请，由行政复议机关对该行政行为的**合法性与适当性**进行审查，并作出复议决定的制度。

#### （二）性质
行政复议行为是**具有司法性质的行政行为**：
1. **行政性**：由行政复议机关按照法律规定实施，本质上属于行政行为；
2. **司法性**：直接目的在于解决行政争议、监督依法行政、维护相对人合法权益，因而带有司法裁判性质。

#### （三）特点（相对于行政诉讼）
| 特点 | 内容 |
|---|---|
| **审理机关** | 由行政机关审理，而非法院 |
| **程序简便** | 程序更为简便、灵活 |
| **审级制度** | 实行**一级复议制度**（一般仅一次复议） |
| **费用** | **不收取费用** |
| **审查深度** | 既审查**合法性**，也审查**适当性**（合理性） |

#### （四）功能与价值
1. 保护公民、法人和其他组织的合法权益；
2. 监督和保障依法行政；
3. 化解行政争议；
4. 促进法治政府建设。

#### （五）基本原则
1. **合法原则**：复议机关本身应依法开展复议工作，对被复议行为的合法性进行审查；
2. **公正原则**：站在中立公正立场，从合法性与适当性两个层面审查，查明事实、公正解决纷争；
3. **公开原则**：过程公开、相关信息公开、结果公开；
4. **高效原则**：严格遵守法定期限，及时进行；
5. **便民为民原则**：尽可能为申请人提供便利条件；
6. **禁止不利处分原则**：《行政复议法》第63条第2款规定，行政复议机关**不得作出对申请人更为不利的变更决定**，但是**第三人提出相反请求的除外**。

> **例外排除**：在行政处罚案件中，若被侵害人与被处罚人同为复议申请人，或被侵害人/被处罚人一方申请复议、另一方作为第三人在复议程序中存在有意识的默示申请撤销处罚决定的行为，则排除禁止不利变更原则的适用。（参见最高法行申4324号，2019）

---

### 二、行政复议范围

#### （一）概念
行政复议范围，指公民、法人或其他组织认为行政机关作出的行政行为侵犯其合法权益时，依法可以向行政复议机关请求审查的行政行为范围。

#### （二）可申请复议的行政行为（《行政复议法》第11条）
| 序号 | 行为类型 | 具体情形 |
|:---:|---|---|
| 1 | **行政处罚** | 对行政处罚决定不服 |
| 2 | **行政强制** | 对行政强制措施、行政强制执行决定不服 |
| 3 | **行政许可** | 申请行政许可被拒绝、法定期限内不予答复，或对有关许可的其他决定不服 |
| 4 | **自然资源确认** | 对确认自然资源所有权或使用权的决定不服 |
| 5 | **征收征用** | 对征收征用决定及其补偿决定不服 |
| 6 | **行政赔偿** | 对赔偿决定或不予赔偿决定不服 |
| 7 | **工伤认定** | 对不予受理工伤认定申请的决定或工伤认定结论不服 |
| 8 | **侵犯经营自主权** | 认为行政机关侵犯经营自主权或农村土地承包经营权、经营权 |
| 9 | **排除限制竞争** | 认为行政机关滥用行政权力排除或限制竞争 |
| 10 | **违法要求履行义务** | 认为行政机关违法集资、摊派费用或违法要求履行其他义务 |
| 11 | **不履行法定职责** | 申请行政机关履行保护人身权、财产权、受教育权等法定职责，行政机关拒绝履行、未依法履行或不予答复 |
| 12 | **行政给付** | 申请行政机关依法给付抚恤金、社保待遇或最低生活保障等，行政机关未依法给付 |
| 13 | **行政协议** | 认为行政机关不依法订立、履行、变更、解除政府特许经营协议、土地房屋征收补偿协议等行政协议 |
| 14 | **政府信息公开** | 认为行政机关在政府信息公开工作中侵犯其合法权益 |
| 15 | **其他行为** | 认为行政机关的其他行政行为侵犯其合法权益 |

#### （三）不可提起行政复议的行政行为
| 类型 | 示例 |
|---|---|
| **国家行为** | 国防、外交等国家行为 |
| **抽象行政行为** | 行政法规、规章或行政机关制定发布的具有普遍约束力的决定、命令等规范性文件 |
| **内部行政行为** | 行政机关对工作人员的奖惩、任免等决定 |
| **民事调解行为** | 行政机关对民事纠纷作出的调解 |

#### （四）可一并审查的规范性文件（《行政复议法》第13条）
公民、法人或其他组织认为行政行为所依据的下列规范性文件不合法，在对行政行为申请行政复议时，可以**一并**向行政复议机关提出对该规范性文件的附带审查申请：
1. 国务院部门的规范性文件；
2. 县级以上地方各级人民政府及其工作部门的规范性文件；
3. 乡、镇人民政府的规范性文件；
4. 法律、法规、规章授权的组织的规范性文件。

> **关键限制**：“一并”意味着**不可单独**针对特定规范性文件提起行政复议，必须依附于对具体行政行为的复议申请。

### 三、行政复议主体

#### （一）行政复议机关
以自己的名义对被申请复议行为进行合法性与适当性审查并作出决定的机关：
1. **县级以上各级人民政府**；
2. 其他依法履行行政复议职责的行政机关（如**国务院部门**）。

#### （二）行政复议机构
行政复议机关办理行政复议事项的机构。可能是行政机关（如司法行政机关），也可能是行政机关内部机构（如国务院部门负责行政复议事务的内部机构）。

#### （三）行政复议申请人
1. 认为合法权益受到行政行为侵犯且对其不服而提起复议的人；
2. 有权申请复议的公民**死亡**的，其**近亲属**可以申请。  
   > “近亲属”包括：配偶、父母、子女、兄弟姐妹、祖父母、外祖父母、孙子女、外孙子女和其他具有扶养、赡养关系的亲属。
3. **无民事行为能力人**或**限制民事行为能力人**的法定代理人；
4. **终止**的法人或其他组织的权利义务承受人；
5. 同一案件申请人人数众多的，可以由申请人**推选代表人**参加行政复议。

#### （四）行政复议被申请人
其行政行为为申请人所不服并被提出行政复议的行政主体（行政机关或法律、法规、规章授权的组织）。
| 情形 | 被申请人确定 |
|---|---|
| 单独作出行政行为 | 该行政主体 |
| 共同作出行政行为 | 共同行政主体 |
| 委托其他主体作出 | 委托的行政主体 |
| 行政主体被撤销 | 职权承受人 |
| 行政机关与不具备行政主体资格的组织共同名义作出 | **行政机关**为被申请人 |

#### （五）行政复议第三人
指与被申请行政复议的行政行为有利害关系并参加到行政复议中的人，但本身不是申请人或被申请人。
- **类型**：
  1. 同被申请行政复议的行政行为有利害关系；
  2. 同行政复议案件处理结果有利害关系（例如：不予A建房许可，A提起复议，新购买相邻房屋的B）。
- **参加方式**：申请参加；行政复议机关通知参加。

#### （六）行政复议队伍（《行政复议法》第6、7、9条）
| 项目 | 内容 |
|---|---|
| **定位** | 专业化、职业化的行政复议人员队伍 |
| **准入条件** | 行政复议机构中初次从事行政复议工作的人员，应当通过**国家统一法律职业资格考试**取得法律职业资格，并参加统一职前培训 |
| **考核管理** | 国务院行政复议机构会同有关部门制定行政复议人员工作规范；对行政复议人员进行业务考核和管理 |
| **培训奖励** | 提高人员素质，对成绩显著者予以奖励 |

### 四、行政复议管辖

#### （一）概念
行政复议的管辖，指公民、法人或其他组织提起行政复议申请之后，应当由**哪一个行政复议机关**来行使复议权。

#### （二）县级以上地方各级人民政府的复议管辖权
**A. 一般情形**
1. 对本级人民政府工作部门作出的行政行为不服；
2. 对下一级人民政府作出的行政行为不服；
3. 对本级人民政府依法设立的派出机关作出的行政行为不服；
4. 对本级人民政府或其工作部门管理的法律、法规、规章授权的组织作出的行政行为不服。

**B. 特殊情形**
1. **省、自治区、直辖市人民政府**同时管辖对本机关作出的行政行为不服的行政复议案件；
2. **省、自治区人民政府依法设立的派出机关**，参照设区的市级人民政府的复议管辖权限；
3. 对地方政府工作部门设立的派出机构**以自己的名义**作出的行政行为，由**本级人民政府**管辖；其中，对直辖市、设区的市人民政府工作部门按行政区域设立的派出机构（如**区公安分局**）的行政行为不服的，也可以由其**所在地的人民政府**管辖。

#### （三）国务院部门的行政复议管辖权
1. 对本部门作出的行政行为不服；
2. 对本部门依法设立的派出机构依照法律、行政法规、部门规章规定，以派出机构的名义作出的行政行为不服；
3. 对本部门管理的法律、行政法规、部门规章授权的组织作出的行政行为不服。

#### （四）垂直领导机关的复议管辖
对**海关、金融、外汇管理**等实行垂直领导的行政机关、**税务**和**国家安全机关**的行政行为不服的，向**上一级主管部门**申请行政复议。

#### （五）对司法行政机关行为不服的复议管辖
对履行行政复议机构职责的地方人民政府司法行政部门的行政行为不服的，可以向**本级人民政府**申请行政复议，也可以向**上一级司法行政部门**申请行政复议。

#### （六）国务院的最终裁决权
对**省级人民政府**和**国务院部门**的行政复议决定不服的，可以向人民法院提起行政诉讼；也可以向**国务院申请裁决**，国务院依照本法规定作出**最终裁决**。

#### （七）提级复议
上级行政复议机关根据需要，**可以审理**下级行政复议机关管辖的行政复议案件。下级行政复议机关对其管辖的案件，也可以**报请上级审理**，由上级决定。

### 五、行政复议的申请与受理

#### （一）行政复议的申请
**1. 概念与原则**  
公民、法人或其他组织不服行政行为，向具有行政复议权的机关提出复议请求。  
> **一行为一复议**：申请人对**两个以上**行政行为不服的，应当**分别申请**行政复议。

**2. 申请方式**
| 方式 | 具体形式/条件 |
|---|---|
| **书面申请** | 当场申请、邮寄申请、网络申请等。行政机关通过互联网渠道送达行政行为决定书的，应当同时提供提交行政复议申请书的互联网渠道 |
| **口头申请** | 书面申请确有困难的，行政复议机关应当当场记录申请人的基本情况、复议请求、主要事实、理由和时间 |

**3. 申请期限**
| 情形 | 期限 |
|---|---|
| **一般期限** | 自知道或应当知道该行政行为之日起**60日内**；法律规定的申请期限超过60日的除外 |
| **未告知权利** | 行政机关未告知复议权利、复议机关和申请期限的，自知道或应当知道上述事项之日起计算，但自知道或应当知道行政行为内容之日起最长不得超过**1年** |
| **最长保护期** | 因不动产提出的申请自行政行为作出之日起超过**20年**，其他申请自作出之日起超过**5年**的，不予受理 |

**4. 申请途径**
- **直接向行政复议机关申请**；
- **通过原行政行为机关提交申请**（《行政复议法》第32条）：
  - 条件：对**当场作出**或依据**电子技术监控设备**记录的违法事实作出的行政处罚决定不服；
  - 处理：原机关收到申请后认为需要维持原决定的，于**5日内**转送复议机关；
  - 目的：使原行政机关有自我审查机会，也减轻复议机关压力。

#### （二）复议前置
对于法律、行政法规规定的某些行政行为，利害关系人不服的，**应先提起复议**；对复议决定不服的，再提起行政诉讼。
1. 对**当场作出**的行政处罚决定不服；
2. 对行政机关作出的侵犯其已经依法取得的**自然资源所有权或使用权**的决定不服；
3. 认为行政机关存在《行政复议法》第11条规定的**未履行法定职责**情形；
4. 申请**政府信息公开**，行政机关不予公开；
5. 法律、行政法规规定应当先申请行政复议的其他情形。

> **告知义务**：对需要复议前置的情形，行政机关在作出行政行为时**应当告知**公民、法人或其他组织先向行政复议机关申请行政复议。

#### （三）行政复议申请的审查
| 项目 | 内容 |
|---|---|
| **审查时限** | **5日**之内进行审查 |
| **审查内容** | **形式的而非实质的**审查 |
| **补正情形** | 申请材料不齐全或表述不清楚，无法判断是否符合受理条件的，自收到申请之日起5日内书面通知补正 |
| **补正要求** | 补正通知应**一次性**载明需要补正的事项；申请人自收到通知之日起**10日内**提交补正材料。有正当理由不能按期补正的，可延长合理期限；无正当理由逾期不补正的，视为放弃申请，记录在案 |

#### （四）行政复议申请的受理
申请符合下列要求的，予以受理：
1. 有明确的申请人和符合本法规定的被申请人；
2. 申请人与被申请行政复议的行政行为有利害关系；
3. 有具体的行政复议请求和理由；
4. 在法定申请期限内提出；
5. 属于本法规定的行政复议范围；
6. 属于本机关的管辖范围；
7. 行政复议机关未受理过该申请人就同一行政行为提出的行政复议申请，并且人民法院未受理过该申请人就同一行政行为提起的行政诉讼。

> **视为受理**：行政复议申请的审查期限届满，行政复议机关未作出不予受理决定的，审查期限届满之日起视为受理。

#### （五）不予受理
对不符合规定的申请，行政复议机关在审查期限内决定不予受理并说明理由；不属于本机关管辖的，还应当在不予受理决定中告知申请人有管辖权的行政复议机关。

#### （六）受理的法律后果
1. 申请人与被申请人之间的行政争议正式进入复议程序；
2. 行政复议程序正式开始，行政复议机关如无法定事由，必须完成全部程序并对行政争议作出决定；
3. **行政复议不停止被申请行政行为的执行**。

### 六、行政复议的审理

#### （一）审理的一般规定
1. **审理程序类别**：普通程序与简易程序；
2. **审理依据**：法律、行政法规、地方性法规、行政规章、自治条例与单行条例。

#### （二）复议期间行政行为不停止执行
行政复议期间，行政行为原则上**不停止执行**。例外情形：
1. 被申请人认为需要停止执行；
2. 行政复议机关认为需要停止执行；
3. 申请人、第三人申请停止执行，行政复议机关认为其要求合理，决定停止执行；
4. 法律、法规、规章规定停止执行的其他情形。

#### （三）行政复议的中止
因法定事由的出现，致使行政复议无法正常进行下去时，由复议机关决定**暂时停止**复议程序，待法定事由消失之后再恢复复议程序。  
> 中止事由：详见《行政复议法》第39条。

#### （四）行政复议的终结
因法定事由的出现，致使行政复议**不可能或没必要**继续进行下去时，由复议机关决定结束复议程序。  
> 终结事由：详见《行政复议法》第41条。

---

> **体系衔接提示**：行政复议作为行政系统内部的层级监督与救济机制，与行政诉讼构成“复议—诉讼”的双轨救济格局。2023年修订的《行政复议法》显著扩大了复议前置范围、强化复议机关的实质化解争议职能，并确立了“一行为一复议”与禁止不利变更等规则，复习时应特别注意新旧制度差异及与《行政诉讼法》的衔接节点。
