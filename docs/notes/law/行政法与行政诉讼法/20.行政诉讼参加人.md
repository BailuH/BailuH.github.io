## 第二十章 行政诉讼参加人

### 一、行政诉讼参加人概述

#### （一）行政诉讼参加人的概念
行政诉讼参加人是指**依法参加行政诉讼活动，享有诉讼权利、承担诉讼义务，并且与诉讼争议或诉讼结果有利害关系的人**。

#### （二）行政诉讼参加人的范围
包括：**原告、被告、第三人、共同诉讼人、诉讼代理人**。

> **注意区分**：行政诉讼“参与人”范围更广，除参加人外还包括证人、鉴定人、勘验人、翻译人等。

#### （三）行政诉讼当事人的特征
1. 以自己的名义进行诉讼；
2. 与行政案件有**利害关系**；
3. 受人民法院裁判的拘束。

---

### 二、原告

#### （一）原告的概念
行政诉讼原告是指**对行政行为不服，依照行政诉讼法的规定向人民法院起诉的人**。  
原告包括：
- 行政行为的**相对人**；
- 其他与行政行为有**利害关系**的公民、法人或其他组织；
- 在**行政公益诉讼**中，**检察机关**也可作为原告。

#### （二）原告资格的构成要件
1. 原告是行政行为的相对人或其他与行政行为**有利害关系**的人，或法律规定的人（如检察机关）；
2. 原告**认为**行政行为侵犯其合法权益（主观标准）；
3. 原告是**依法向人民法院提起诉讼**的人。

> **利害关系**指行政行为对当事人的权利义务已经或必然产生实际影响。<br>
> 认定时通常考虑：
> 1. 是否存在一项**权利**（且属主观权利）；
> 2. 该权利是否**可能受到**行政行为的侵害；
> 3. 侵害与行政行为之间是否有**因果关系**。

> 💡 “保护规范理论”的内涵
   如果法规范制定是有利于特定人或者特定范围的人，并满足这些人的个人利益，而不仅仅是保护公共利益，那么，该法规范就是个人在公法上主张权利的依据。换言之，是不是有权利存在，还要看行政实体法的目的是不是至少包括保护特定相对人的合法权益。

#### （四）《行诉法适用解释》规定的“与行政行为有利害关系”情形
1. 被诉行政行为涉及其**相邻权**或者**公平竞争权**；
2. 在行政复议等行政程序中**被追加为第三人**；
3. 要求行政机关**依法追究加害人法律责任**；
4. **撤销或者变更**行政行为涉及其合法权益（如购买依许可建造房屋的人）；
5. 为维护自身合法权益向行政机关**投诉**，行政机关作出或未作出处理；
6. 其他与行政行为有利害关系的情形。

#### （五）原告资格的转移
1. 有权提起诉讼的公民死亡 → **近亲属**可以提起诉讼。  
   近亲属包括：配偶、父母、子女、兄弟姐妹、祖父母、外祖父母、孙子女、外孙子女和其他具有扶养、赡养关系的亲属。
2. 有权提起诉讼的法人或其他组织终止 → 承受其权利义务的法人或其他组织可以提起诉讼。

#### （六）特殊情形下原告资格的确定
1. **合伙企业**：以核准登记的**字号**为原告；未依法登记的，全体合伙人为共同原告。
2. **个体工商户**：有字号的，以字号为原告（注明经营者信息）；无字号的，以经营者为原告。
3. **股份制企业**：股东大会、股东会、董事会等认为行政行为侵犯企业经营自主权的，**可以企业名义**提起诉讼。
4. **联营、合资、合作企业**：联营、合资、合作各方认为企业权益或自己一方权益受侵害的，**可以自己名义**起诉。  

> 注：随着《外商投资法》施行及《市场主体登记管理条例》实施，联营企业、中外合资/合作企业类型逐步退出，但既有案件仍可参照。

5. **非国有企业**被行政机关注销、撤销、合并、强令兼并、出售、分立或改变企业隶属关系的，**该企业或者其法定代表人**可以提起诉讼。  

> 国有企业不适用此规则。

6. **非营利法人**（事业单位、社会团体、基金会、社会服务机构等）的出资人、设立人认为行政行为损害法人合法权益的，可以自己名义起诉。
7. **业主委员会**对涉及业主共有利益的行政行为，可以自己名义起诉；业主委员会不起诉的，**专有部分占建筑物总面积过半数或者占总户数过半数的业主**可以起诉。
8. **债权人**：行政机关作出行政行为时依法应予保护或考虑债权人权益的，债权人认为行政行为损害债权实现，可提起行政诉讼（如抵押权人对房屋登记行为）。

#### （七）检察机关作为行政公益诉讼原告
**法律依据**：《行政诉讼法》第25条第4款  
**适用领域**：
1. 生态环境和资源保护；
2. 食品药品安全；
3. 国有财产保护；
4. 国有土地使用权出让；
5. 其他领域（逐步扩展）。

**条件**：
- 负有监管职责的行政机关**违法行使职权或不作为**；
- 致使**国家利益或者社会公共利益**受到侵害。

**程序**：
1. 先向行政机关提出**检察建议**，督促其依法履职；
2. 行政机关**不依法履职**的，人民检察院依法向人民法院提起诉讼。

### 三、被告

#### （一）被告的概念
行政诉讼被告是指**原告起诉其行政行为侵犯自己合法权益，并经人民法院通知应诉的行政主体**（行政机关或法律、法规、规章授权的组织）。

#### （二）被告的特征
1. 被告是**行政主体**（不是国家，也不是工作人员个人）；
2. 被告是被指控行政行为侵犯原告合法权益的行政主体；
3. 被告是被起诉并由法院通知应诉的行政主体；
4. 被告是行政机关或**法律、法规、规章授权的组织**。

#### （三）被告的确认规则（详细列表）

| 情形               | 被告确认规则                                                                                                                                                                                              |
| :--------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **直接起诉**         | 作出行政行为的行政机关（==一般规则：谁行为，谁被告==）                                                                                                                                                                       |
| **经复议的案件**       | 1️⃣==若复议维持==：**作出原行政行为的行政机关 + 复议机关** 为共同被告<br>（复议机关驳回复议申请。请求，但以复议申请不符合受理条件为由驳回的除外）<br>2️⃣==若复议改变==：**复议机关**为被告<br>（核心在于看是否==改变处理结果==）<br>3️⃣==若复议不作为==：起诉原行政行为的 → 原行政机关为被告；<br>起诉复议机关不作为的 → 复议机关为被告 |
| **共同行政行为**       | **共同作出**的行政机关为共同被告                                                                                                                                                                                  |
| **委托行政**         | **委托的行政机关**为被告<br>（1️⃣无法律、法规、规章授权，行政机关授权内设机构/派出机构/其他组织的；2️⃣下文提到的所谓“种类越权”，均视为==委托==）                                                                                                                 |
| **行政机关被撤销或职权变更** | **继续行使其职权的行政机关**为被告；没有继续行使职权的，以**所属人民政府**为被告（若垂直领导的：以垂直领导的上一级行政机关为被告）                                                                                                                               |
| **经批准的行政行为**     | 以对外发生法律效力的文书上**署名的机关**为被告                                                                                                                                                                           |

| 情形                   | 被告确认规则                                                                                                      |
| :------------------- | :---------------------------------------------------------------------------------------------------------- |
| **行政机关组建的无独立承担能力机构** | 以**组建该机构的行政机关**为被告                                                                                          |
| **法律、法规、规章授权**       | **被授权的组织**为被告<br>（超出授权范围但属==幅度越权==，仍以该组织为被告；==种类越权==视为委托）                                                   |
| **开发区管理机构**          | - 国务院、省级政府批准设立的：以该**开发区管理机构**为被告；<br>- 其职能部门：以**职能部门**为被告；<br>- 其他开发区：以**开发区管理机构**为被告；无主体资格：以**设立的地方政府**为被告 |
| **村民委员会 / 居民委员会**    | 依据**法律、法规、规章授权**履行行政管理职责的，以**村委会/居委会**为被告                                                                   |
| **高等学校、行业协会等**       | 依据**法律、法规、规章授权**实施行政行为的，以**该事业单位、行业协会**为被告                                                                  |
| **房屋征收部门**           | 以**房屋征收部门**为被告（如征收办公室等）                                                                                     |

> ❓ 如何理解“房屋征收部门”
> 是”委、办、局“等常驻机关，但是一般不考虑专门（临时组建的）“征收办公室”——==不过有争议==<br>不过在现在的实践中，一些地区（如浙江），会直接指定更下级的政府来主持工作，那么自然视作委托，可以避免争议。

#### （四）被告不适格或应追加被告的处理
1. 原告起诉的被告不适格 → 法院告知**变更被告**；不同意变更的，**裁定驳回起诉**。
2. 应当追加被告而原告不同意追加 → 法院通知其以**第三人**身份参加诉讼。  
   **例外**：复议机关作共同被告的情形，原告只起诉其一，法院告知追加而原告不同意 → 法院应当将另一机关**列为共同被告**。

### 四、共同诉讼人与诉讼代表人

#### （一）共同诉讼的概念
共同诉讼是指**当事人一方或双方为二人以上**，因**同一行政行为**发生，或者因**同类或相关行政行为**发生、法院认为可以合并审理并经当事人同意的诉讼。

#### （二）共同诉讼的种类
1. **必要的共同诉讼**：因**同一行政行为**引发，法院==必须合并审理==。  
   - 共同原告：同一处罚中的共同被处罚人、共同被侵害人、被处罚人与被侵害人等。  
   - 共同被告：共同作出行政行为的行政机关。
1. **普通的共同诉讼**：因**同类或相关行政行为**发生，法院认为==可以合并==审理且当事人同意。  
   - 例如：两个以上行政机关分别对同一事实作出行政行为；行政机关就同一事实对多人分别作出行政行为；诉讼中被告对原告作出新行政行为等。

> 💡 法院的原则一般是“**一行为一诉**”

#### （四）诉讼代表人
当事人一方**人数众多**（一般指十人以上）的共同诉讼，可以**推选代表人**进行诉讼。  
- 推选不出的，法院可以在起诉的当事人中**指定**；  
- 代表人为**二至五人**；  
- 代表人变更、放弃诉讼请求或承认对方诉讼请求，须经**被代表的当事人同意**。

### 五、第三人

#### （一）第三人的概念
行政诉讼第三人是指**与被诉行政行为有利害关系但没有提起诉讼，或者同案件处理结果有利害关系，经申请参加诉讼，或者由人民法院通知参加诉讼的公民、法人或其他组织**。

#### （二）第三人的特征
1. 与被诉行政行为或案件处理结果有**利害关系**；
2. 未提起诉讼；
3. 在诉讼开始后、审结前参加诉讼；
4. 可主动申请或由法院通知参加。

#### （三）第三人的种类

**1. 类似于原告地位的第三人**  
- 行政处罚案件中的**被处罚人**或**受害人**；  
- 行政确权案件中的**被确权人**或**其他主张权利的人**；  
- 行政许可案件中的**被许可人**或**许可争议人**；  
- 行政裁决案中不服裁决起诉者的**相对方**；  
- 受行政行为影响的**未起诉的其他利害关系人**。

**2. 类似于被告地位的第三人**  
- 行政行为是被告与**另一行政主体**的共同行为（另一行政主体作为第三人）；  
- 行政主体与**不具有行政主体资格的个人或组织**联合署名作出行政行为，被诉时，该个人或组织可作为第三人；

> 什么组织会出现上条情况呢？例如，“爱国卫生委员会” 、“乡党委与县政府”中的党委（==有争议==）

- **两个作出相互矛盾行政行为的行政机关**，其中一个被诉，另一个可作为第三人参加诉讼。  
  （例：A机关发放许可，B机关以未经许可为由处罚，被处罚人起诉B机关，A机关可作为第三人）

### 六、诉讼代理人

#### （一）诉讼代理人的概念
诉讼代理人是指**以当事人名义，在代理权限内，代理当事人进行行政诉讼活动，其诉讼法律后果由被代理人承担的人**。

#### （二）代理人的特征
1. 以被代理人名义活动；
2. 在**代理权限范围内**活动；
3. 法律后果由被代理人承担；
4. 产生方式：法律规定、法院指定、当事人委托。

#### （三）法定代理人
- 直接根据**法律**规定，代理**无诉讼行为能力的公民**进行诉讼的人。  
- 一般由**监护人**担任；法定代理人互相推诿的，人民法院可指定其中一人代理。

#### （四）指定代理人
- 基于**人民法院指定**，代理当事人进行诉讼。  
- 主要适用于法定代理人互相推诿代理责任的情形。

#### （五）委托代理人
**委托代理人的范围**（《行政诉讼法》第31条）：  
1. **律师、基层法律服务工作者**；  
2. 当事人的**近亲属或者工作人员**；  
3. 当事人所在**社区、单位以及有关社会团体推荐的公民**。

**社会团体推荐公民担任诉讼代理人的限制条件**（《行诉法适用解释》第33条）：  
- 社会团体属于**依法登记设立或免予登记的非营利性法人**；  
- 被代理人属于该社会团体的**成员**，或者当事人一方住所地位于该团体的活动地域；  
- 代理事务属于该社会团体**章程载明的业务范围**；  
- 被推荐的公民是该社会团体的**负责人**或者与该团体有**合法劳动人事关系的工作人员**。
