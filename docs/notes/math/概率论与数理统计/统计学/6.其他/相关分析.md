## 一、为什么需要相关分析？

在研究中，我们常常需要回答：**两个变量之间是否存在关联？这种关联有多强？**

例如：
- 学习时长与考试成绩是否有关？
- 气温与冰淇淋销量是否有关？
- 客户满意度与复购意愿是否有关？

相关分析的核心目标，就是**量化两个变量共同变化的程度和方向**。

## 二、起点：协方差（Covariance）

### 2.1 直观思想

协方差衡量的是：**两个变量各自偏离其均值后，乘积的平均趋势。**

- 如果 $X$ 和 $Y$ 经常同时大于各自均值（或同时小于），乘积多为正 → **正协方差**
- 如果 $X$ 大于均值时 $Y$ 往往小于均值，乘积多为负 → **负协方差**
- 如果两者偏离方向杂乱无章，正负抵消 → **协方差接近 0**

### 2.2 公式

**总体协方差：**

$$\text{Cov}(X, Y) = \frac{1}{N}\sum_{i=1}^{N}(X_i - \mu_X)(Y_i - \mu_Y)$$

**样本协方差（无偏估计）：**

$$\text{Cov}(X, Y) = \frac{1}{n-1}\sum_{i=1}^{n}(X_i - \bar{X})(Y_i - \bar{Y})$$

### 2.3 协方差的局限性

协方差有一个致命缺陷：**它有量纲，取值范围没有上界。**

- 身高的单位是 cm，体重的单位是 kg，算出来的协方差数值本身难以直观判断"强"还是"弱"。
- 如果把身高从 cm 换成 m，协方差数值会缩小 100 倍，但变量间的关系强度并没有改变。

> **因此，我们需要对协方差进行"标准化"，消除量纲影响，得到一个介于 -1 和 1 之间的无量纲指标。**

## 三、Pearson 积矩相关系数（Pearson's $r$）

### 3.1 核心思想：标准化协方差

Pearson 相关系数本质上就是**标准化后的协方差**——用两个变量的标准差对协方差进行归一化。

$$r = \frac{\text{Cov}(X, Y)}{S_X \cdot S_Y}$$

### 3.2 展开形式

**定义式（概念版）：**

$$r = \frac{\sum_{i=1}^{n}(X_i - \bar{X})(Y_i - \bar{Y})}{\sqrt{\sum_{i=1}^{n}(X_i - \bar{X})^2}\sqrt{\sum_{i=1}^{n}(Y_i - \bar{Y})^2}}$$

- **分子**：协变和（Sum of Products, SP），反映 $X$ 与 $Y$ 共同偏离均值的方向和程度
- **分母**：两个变量离差平方和的几何平均，起到标准化作用

**计算式（实用版）：**

$$r = \frac{n\sum XY - \sum X \sum Y}{\sqrt{[n\sum X^2 - (\sum X)^2][n\sum Y^2 - (\sum Y)^2]}}$$

此式不需要先算均值，适合直接代入原始数据计算。

### 3.3 取值与解释

| $r$ 的绝对值 | 相关程度（经验参考） |
|-------------|-------------------|
| 0.00 - 0.19 | 极弱 / 几乎无相关 |
| 0.20 - 0.39 | 弱相关 |
| 0.40 - 0.59 | 中等相关 |
| 0.60 - 0.79 | 强相关 |
| 0.80 - 1.00 | 极强相关 |

> ⚠️ 注意：上述划分仅为经验参考，不同学科领域标准不同。且**相关不等于因果**。

### 3.4 适用条件与局限

**适用条件：**
1. **线性关系**：Pearson $r$ 只度量线性相关。若变量呈 U 型关系，$r$ 可能接近 0，但两者并非无关。
2. **连续变量**：要求变量为定距或定比尺度。
3. **近似正态分布**：对极端异常值敏感。
4. **无明显异常值**：个别极端值可能严重扭曲 $r$。

**局限：**
- 对**非线性单调关系**（如对数关系、指数关系）无能为力
- 对**异常值敏感**
- 对**定序数据**直接计算不合理（把类别标签当连续数值，假设各类别间距相等）

> 当我们遇到定序数据、存在异常值、或怀疑关系是非线性单调时，就需要引入**秩相关**方法。

## 四、Spearman 秩相关系数（Spearman's $\rho$）

### 4.1 核心思想："用秩次替代原始值"

Spearman 相关系数的本质是：

> **将原始数据转换为秩次（rank）后，对秩次计算 Pearson 相关系数。**

由于秩次消除了原始数值的具体大小和量纲，只保留**相对顺序**，因此：
- 不受异常值影响（稳健）
- 不要求线性关系，能捕捉**单调关系**（单调递增或递减）
- 适用于**定序数据**

### 4.2 计算步骤

1. 将 $X$ 变量从小到大排序，赋予秩次 $R(X_i)$（如有相同值，取平均秩次）
2. 将 $Y$ 变量从小到大排序，赋予秩次 $R(Y_i)$
3. 计算每对观测的**秩次差**：$d_i = R(X_i) - R(Y_i)$
4. 代入公式：

$$r_s = 1 - \frac{6\sum d_i^2}{n(n^2 - 1)}$$

### 4.3 与 Pearson 的关系

- **无结（tie）时**：上述公式与"对秩次直接算 Pearson $r$"**数学完全等价**
- **有结时**：需要用 Pearson 公式对秩次直接计算，或进行结校正
- Spearman 是 Pearson 的**非参数版本**

### 4.4 适用场景

- 数据存在**异常值**或极端值
- 变量间关系可能是**非线性单调**（如对数、指数关系）
- 变量为**定序尺度**（如满意度等级、比赛名次）
- 数据不满足正态分布假设

---

## 五、Kendall 秩相关系数（Kendall's $\tau$）

### 5.1 核心思想："成对比较"

Kendall 相关系数采用与 Spearman 完全不同的思路：

> **考察所有可能的两两观测对，看它们在两变量上的排序是否一致。**

- **一致对（Concordant）**：$X_i < X_j$ 且 $Y_i < Y_j$，或 $X_i > X_j$ 且 $Y_i > Y_j$
- **不一致对（Discordant）**：$X_i < X_j$ 但 $Y_i > Y_j$，或反之

### 5.2 公式

$$\tau = \frac{n_c - n_d}{\frac{1}{2}n(n-1)}$$

其中：
- $n_c$ = 一致对的数量
- $n_d$ = 不一致对的数量
- 分母 = 所有可能的两两组合数

### 5.3 与 Spearman 的区别

| 对比维度 | Spearman $\rho$ | Kendall $\tau$ |
|---------|----------------|----------------|
| **计算基础** | 秩次差的平方 | 成对排序一致性 |
| **对异常的敏感度** | 中等（受极端秩次影响） | 较低（基于成对比较） |
| **统计效能** | 较高 | 略低（但更稳健） |
| **直观解释** | 秩次的线性相关 | "一致概率 - 不一致概率" |
| **样本量小** | 尚可 | 更稳健 |
| **存在大量结** | 需校正 | 需校正，但相对更稳定 |

> 经验上，对同一组数据通常有 $|r| \geq |r_s| \geq |\tau|$。

### 5.4 适用场景

- 样本量**较小**
- 数据中存在**大量相同值（结）**
- 希望获得**概率化解释**（如"有 70% 的成对比较是一致的"）
- 对稳健性要求极高

## 六、Polychoric 相关系数（多相关系数）

### 6.1 问题背景：定序数据的"尴尬"

当面对 Likert 量表（1=非常不同意, 2=不同意, 3=一般, 4=同意, 5=非常同意）时：

- **Pearson**：直接把 1,2,3,4,5 当连续数值，默认各类别间距相等，通常**低估**真实相关
- **Spearman**：只用排序信息，忽略了各类别的**频率分布**
- 两者都**没有充分利用**定序数据的特点

### 6.2 核心思想：潜变量假设

Polychoric 相关基于一个关键假设：

> **观测到的有序分类变量，是由一个潜在的、服从正态分布的连续变量，通过若干个阈值（thresholds）切割离散化后得到的。**

**Polychoric 相关系数**估计的就是这两个**潜在连续变量**之间的线性相关——即它们的 **Pearson $r$**。

### 6.3 估计方法

不同于 Pearson/Spearman 的直接公式计算，Polychoric 相关通过**最大似然估计（MLE）**求解：

1. 根据观测到的两变量联合频数表（列联表）
2. 假设潜变量服从**二元正态分布**
3. 通过迭代算法，寻找能使观测频数出现概率最大的潜变量相关系数

### 6.4 特殊情况：Tetrachoric 相关

当两个变量都只有 **2 个类别**（二分类）时，Polychoric 相关退化为 **Tetrachoric 相关**（四分相关系数）。原理完全相同：假设两个二分类背后各有一个潜在连续变量，估计它们之间的 Pearson 相关。

### 6.5 Polychoric 相关矩阵

在结构方程模型（SEM）、验证性/探索性因子分析（CFA/EFA）中，当变量为定序尺度时：

1. 对每两个变量计算 Polychoric 相关系数
2. 组合成方阵，即 **Polychoric 相关矩阵**
3. 以此矩阵作为因子分析或 SEM 的输入

这是处理定序数据潜变量建模的**标准做法**（如 Mplus、lavaan 等软件）。

## 七、四种相关系数对比总结

| 维度 | **Pearson $r$** | **Spearman $\rho$** | **Kendall $\tau$** | **Polychoric** |
|------|-----------------|---------------------|--------------------|----------------|
| **数据尺度** | 定距/定比（连续） | 至少定序 | 至少定序 | 定序（假设潜连续） |
| **度量目标** | **线性相关** | **单调相关** | **单调相关** | **潜变量的线性相关** |
| **计算基础** | 原始离均差乘积 | 原始数据的**秩次** | 成对排序**一致性** | 二元正态**似然估计** |
| **分布假设** | 观测变量近似正态 | 无严格假设 | 无严格假设 | **潜变量**二元正态 |
| **对异常值** | **敏感** | **稳健** | **稳健** | 较稳健 |
| **对非线性** | 只能线性 | 可捕捉单调 | 可捕捉单调 | 依赖潜变量模型 |
| **与 Pearson 关系** | 基准 | 对秩次算 Pearson | 不同算法，目的类似 | **估计潜变量的 Pearson** |
| **典型应用场景** | 连续正态数据、线性关系 | 有异常值、定序数据、单调非线性 | 小样本、大量结、高稳健要求 | 定序量表、因子分析、SEM |

## 八、方法选择指南

```
变量类型与分布特征
        |
        ├─ 两个变量均为连续变量
        |       |
        |       ├─ 近似正态、无明显异常值、关系呈线性
        |       |       → Pearson r
        |       |
        |       └─ 有异常值、非线性单调、不满足正态
        |               → Spearman ρ
        |
        └─ 至少一个变量为定序/等级变量
                |
                ├─ 简单分析、样本量适中
                |       → Spearman ρ（最常用）
                |
                ├─ 样本量小、大量相同值（结）
                |       → Kendall τ
                |
                └─ 用于因子分析、结构方程模型（SEM）
                        → Polychoric 相关矩阵
```

## 十、注意事项

1. **相关 ≠ 因果**：即使 $r = 0.99$，也不能说明 $X$ 导致 $Y$，可能存在第三变量、反向因果或巧合。
2. **零相关 ≠ 无关**：Pearson $r = 0$ 只说明没有线性关系，可能存在强非线性关系（如 U 型）。
3. **对称性**：所有上述相关系数都是对称的，$r_{XY} = r_{YX}$，不区分自变量和因变量。
4. **范围**：四种系数均取值于 $[-1, 1]$，-1 表示完全负向关联，+1 表示完全正向关联，0 表示无线性/单调关联。
5. **统计显著性**：相关系数的大小需要结合样本量进行显著性检验，小样本中即使 $r$ 较大也可能不显著。
