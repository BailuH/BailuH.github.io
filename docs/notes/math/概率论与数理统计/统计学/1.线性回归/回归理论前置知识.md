> 💡在学习回归的是时候：我经历了很长一段时间的迷惘——*回归的本质是什么？它和相关分析的区别与联系在哪？【我似乎总有一种想要用一方代替或部分代替另一方的感觉】*
> 事实上它们在知识内容上也总有一些纠葛——为什么相关系数的平方就得到了决定系数？

## 变量之间的关系（尤其是相关关系）
- 变量之间有两类关系——确定性关系（能用函数表示）和相关性关系（无法用函数表示）

### 相关关系的分类
- **按相关程度**：完全相关、不完全相关、不相关
- **按相关方向**：正相关（同向变化）、负相关（反向变化）
- **按相关形态**：线性相关（散点图近似呈直线）、非线性相关（曲线关系）
- **按变量个数**：单相关（两个变量）、复相关（一个变量与多个变量）、偏相关（控制其他变量后两个变量的关系）

### 相关关系的识别工具——散点图
- 散点图是直观判断变量间关系形态和强弱的第一步工具
- 通过散点图可以初步判断：是否存在关系、关系的方向、关系的形式（线性/非线性）、关系的强弱


## 为什么相关分析可以与回归分析分治（解除疑惑）

- 相关性关系虽不能用函数刻画，但是却可以用某种指标去刻画变量间相关性的大小（例如相关系数、斯皮尔曼系数等），算出指标大小后再利用假设检验的方法，做出统计判断，这就是相关分析的任务。

- 另一方面，由于高尔顿等人的研究，"==子代的平均高度有向中心回归的趋势=="，使得一段时间内人的身高相对稳定。这意味着，尽管相关关系不能用函数关系来来表示，但==在平均意义下==有一定的**定量关系表达式**，寻找这种定量关系表达式就是回归分析的主要任务。

### 相关分析与回归分析的系统对比

| 对比维度 | 相关分析 | 回归分析 |
|---------|---------|---------|
| **研究目的** | 衡量变量间关联的强弱与方向 | 建立变量间的定量关系式，用于预测和控制 |
| **变量地位** | 变量对称，不分自变量和因变量 | 变量不对称，区分自变量（解释变量）$x$ 和因变量（被解释变量）$y$ |
| **数学表达** | 计算相关系数 $r$（或其他相关指标） | 建立回归方程 $\hat{y} = f(x)$ |
| **因果含义** | 不隐含因果关系，仅描述伴随关系 | 隐含因果方向（$x \to y$） |
| **量纲影响** | 相关系数无量纲，不受量纲影响 | 回归系数有量纲，受量纲影响 |
| **应用侧重** | 初步探索变量关系 | 预测、解释、控制 |

### 二者的联系
- 同一组数据的相关分析与回归分析，其符号（正负）是一致的
- 相关系数 $r$ 的平方 $r^2$ 就是**决定系数**（判定系数），表示因变量的变异中能被自变量解释的比例
- 只有当变量间存在显著的线性相关时，建立线性回归模型才有意义


## 回归分析中的几个核心概念

### 总体回归函数（PRF）与样本回归函数（SRF）
- **总体回归函数**：描述总体中因变量 $y$ 的条件期望与自变量 $x$ 之间的关系：
  $$E(y|x) = \beta_0 + \beta_1 x$$
  其中 $\beta_0, \beta_1$ 是总体参数，不可直接观测。

- **样本回归函数**：利用样本数据估计得到的回归方程：
  $$\hat{y}_i = \hat{\beta}_0 + \hat{\beta}_1 x_i$$
  其中 $\hat{\beta}_0, \hat{\beta}_1$ 是总体参数的估计值。

### 随机误差项与残差
- **随机误差项** $\varepsilon_i$ ：总体模型中 $y_i = \beta_0 + \beta_1 x_i + \varepsilon_i$，包含所有未被模型解释的随机因素
- **残差** $e_i$（或 $\hat{\mu}_i$）：样本模型中 $e_i = y_i - \hat{y}_i$，是随机误差项的样本估计


## 高斯-马尔可夫定理

> 虽然很多情况下，高斯-马尔可夫定理总是在==多元线性回归==的时候才介绍，但是我认为在开始学习回归分析之前先接触一下，会对后续回归分析的一系列"==后续操作=="有更深刻的理解。
> 虽然这个定理描述的是多元线性回归的情况（矩阵语言描述），但是只需要将其内容==标量化==就能得到一元的情况，**定理背后的思想与方法都是不变的**。

### 经典线性回归模型的基本假设（高斯-马尔可夫前提）

对于总体回归模型 $y = X\beta + \mu$，需要满足以下假设：

1. **线性于参数**：模型对参数 $\beta$ 是线性的（变量本身可以是非线性的变换，如 $x^2, \ln x$）
2. **随机抽样**：样本 $(y_i, X_i)$ 是随机抽取的，独立同分布
3. **无完全多重共线性**：自变量之间不存在完全的线性关系（$X$ 满列秩）
4. **零条件均值**（外生性）：$E(\mu|X) = 0$，即误差项与所有自变量不相关
5. **同方差性**：$Var(\mu_i|X) = \sigma^2$（常数），误差项方差不随自变量变化
6. **无自相关**：$Cov(\mu_i, \mu_j|X) = 0 \quad (i \neq j)$，不同观测的误差项互不相关

> 注：若进一步假设误差项服从正态分布 $\mu \sim N(0, \sigma^2 I)$，则可以在小样本下进行精确的 $t$ 检验和 $F$ 检验。

### 定理内容

在上述假设1-6成立的条件下，**普通最小二乘估计量（OLS）** $\hat{\beta}$ 是所有**线性无偏估计量**中方差最小的——即 OLS 估计量是 **BLUE**（Best Linear Unbiased Estimator，最佳线性无偏估计量）。

### 定理解读
- **线性**：估计量 $\hat{\beta}$ 是 $y$ 的线性组合
- **无偏**：$E(\hat{\beta}) = \beta$，估计量的期望等于真实参数
- **最佳（有效）**：在所有满足线性和无偏的估计量中，OLS 的方差最小

### 定理的意义
- 高斯-马尔可夫定理为 OLS 方法提供了**理论依据**：在满足基本假设时，OLS 是最优的线性估计方法
- 它解释了为什么回归分析中"默认"使用最小二乘法——不是因为习惯，而是因为它在理论上具有最优性
- 当某些假设不满足时（如异方差、自相关），OLS 不再是 BLUE，这也是后续学习**加权最小二乘（WLS）**、**广义最小二乘（GLS）等**方法的原因
- 如果存在异方差，可以使用稳健标准误（Robust Standard Errors）来修正；如果存在自相关，需要用到自回归修正等方法
